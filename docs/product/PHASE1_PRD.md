# Phase1 product requirements

ZIGoals is the independent Goal Layer for ZIGChain: “Your goals. Onchain.” A goal, its progress and the required contribution come before protocols or returns.

Milestone1 delivers one-owner idle goals: connect Keplr testnet, view address/balance; create a private plan and empty financial record; deposit/add funds, withdraw, close empty goal; read progress, remaining amount, planned/required contributions, deadline, projected completion, Funding Health, activity and advanced verification. Local browser simulation supports these flows without funding/whitelist and is explicitly labelled. It is not a deployed chain.

Templates: Emergency Fund, First Home, Travel, Education, Financial Freedom, Custom. Names/targets/currency/date/starting-plan/monthly-plan/risk/liquidity/date-flexibility remain private on device. Creating a record does not silently deposit its starting plan. Contributions are manual. Export/import version1 backups; missing plans never disable withdrawals.

Funding Health uses zero future return. Scenario assumptions use effective monthly rate, end-of-period contributions, original-day calendar clamping, no partial month contribution/return. Health states are COMPLETED/AHEAD/ON_TRACK/BEHIND with explanations. Fiat views are marked demo valuation, never real wealth. All transfers use integer native base units.

Dark navy consumer interface, cyan/violet accents, responsive layouts, semantic form labels, keyboard focus, textual states, reduced motion. Wallet errors and uncertain chain confirmation must be explicit. Advanced data belongs in optional disclosure.

Excluded: token/DAO/governance, social feed, transferable/shared/family goals, strategy marketplace, production AI, autonomous signing/optimization/debits/rebalancing, cross-chain/fiat/RWA/embedded wallets, native mobile apps, mainnet, billing, real-money movement. External integrations require canonical interface evidence first.
