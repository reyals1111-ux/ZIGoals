# My links (Session W Part 19)

The person's own socials, apps and sites as buttons on Today.

- **Where:** Settings → My links (add, edit, move up/down, remove with a confirmation); Today → "My links" (a folded row on
  a phone). Show or hide the Today card under Settings → Your pages & buttons → My links.
- **What is kept:** settings v3 `links` (synced with Today's settings): a name (up to 40 characters), an https address,
  an icon and the order; up to 24 links. The first saved link raises Today's settings to v3 (see SYNC_HOMES for the
  rollback note). Exports include it (Export everything, `links.csv`).
- **Addresses:** https only, with a host and no user name or password. ZIGoals keeps the address exactly as typed (it adds
  and removes nothing, so no tracking parameter is ever added) and never loads anything from it (no favicon, no preview).
  Each button opens in a new tab with no opener and no referrer.
- **Icons:** ZIGoals' own plain pictures of what a network is for, never a logo, shape or colour of the brand: a camera
  (Instagram), a note (TikTok), a play button (YouTube), a cross (X), two people (Facebook), a briefcase (LinkedIn), a
  forum bubble (Reddit), a game controller (Discord), a TV (Twitch), code brackets (GitHub), headphones (Spotify), a chat
  bubble (WhatsApp), an envelope (Telegram), a route (Strava), a board (chess.com), a chess clock (Lichess). The person's
  label always names the site; any other site gets the label's first letter. The address suggests the picture until the
  person chooses one.
- **Showcase:** four fictional links to reserved example addresses (example.com, example.org, example.net).
