## Production-build spec results (first pass: 4 failed, 9 skipped) — what changed

- hud-look (d) Dark border parity: the old sheet let `.nova-widget` override the Holo rim; the regenerated sheets (5e54e15a) keep `.nova-widget[data-holo]` (1,2,0) above it. Sheets must be regenerated again after this pass's CSS.
- hud-look (e): app cause — the View controls panel stayed open when the focus moved to the toast; it now closes on focus leave (nova-command.tsx); the spec asserts that.
- hud-perf: app cause — turning ornaments were groups inside the data SVGs (main-thread repaint every frame) and the orb breathed inside its SVG; both are compositor layers now. The integrator measures.
- hud-two-way: Health links are full loads by design (camera permission), so that step proves the record, not "no reload"; the live no-reload claims stay.
- Skips: the 9 were the mobile project skipping computer-only specs (de-duplication). Stillness now also runs on a 390 px phone in both projects; the perf skip is a true capability skip (CDP throttling, laptop target).

- Target met on the median: 60 fps at CPU 4× in Full motion; idle while hidden is about 2 % of one core (guard 20 %), with
  nothing drawn on the sky canvas and no HUD animation running.
- The first two runs of the suite failed this spec at median 50 ms (20 fps). Cause: the spec, not the HUD. The suite's
  `trace: 'retain-on-failure'` records a screencast frame for every visual change; with the trace on, the same build
  measured median 50 ms, with it off 16.7 ms (same page, same throttle; and 16.7 ms with the trace on once the CSS
  animations were paused, so the cost scales with what moves, as a recorder's does). The spec now sets `trace: 'off'`.
- Breakdown (diagnostic, trace off, 4 s at 4×): main-thread task time 0.86–1.09 s, of which style recalculation
  0.19–0.22 s (the 12 running CSS animations) and script 0.17–0.25 s; hiding the sky canvas changed neither the median
  (16.7 ms) nor the script time much (0.24 s). Pausing the CSS animations brought the p95 to 16.8 ms and style work to
  ~0: the p95 tail is the ornaments' style recalculation, a candidate for the next pass (not a failure).
- Phones: not measured (true capability skip; the target is a laptop profile).
