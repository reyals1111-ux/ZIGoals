# Native-quality mobile roadmap — deferred

Milestone1 is responsive web. Future iOS/Android companion begins with dashboard, progress/health, portfolio/value, contributions, activity, milestones and consent-based push notifications. Later: create, fund, withdraw, change plan, approved strategy management.

Preserve independent engine/config/schema packages for reuse. Native wallet approval, deep links, background lifecycle, offline/private metadata and account switching need platform-specific threat reviews. Evaluate Face ID/biometrics, passkeys, recovery and portability without exposing keys to AI. A native shell is not evidence of secure signing. No native app implemented here.
