# Mainstream onboarding — deferred

Future flow: bank/card → regulated fiat provider → suitable stable asset → ZIGChain → goal → approved strategy. Exit must return through a supported stable asset and regulated off-ramp to a bank/payment method. Use specialist providers; do not build banking infrastructure.

Prerequisites: legal/compliance review, jurisdiction eligibility, KYC/AML, provider due diligence, reliable cash-out, clear fees/risks, stablecoin liquidity, embedded/passkey-wallet recovery and portability, optional supported gas sponsorship. Simple mode prioritizes outcomes; advanced mode discloses assets, custody, contracts, fees and redemption. Never hide material financial facts. No fiat, embedded wallet or regulatory implementation in Phase1.
