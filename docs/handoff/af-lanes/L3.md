## Merge early: the path engine model (step 1)
`apps/web/lib/path/model.ts` + `colours.ts` (+ `model.test.ts`) are pure and React-free and committed on their own so the
lead can merge them first for the Earn lane's Start-here path and Academy. The shape:
- `PathModel = {id, label?, sections: PathSection[], milestones: PathMilestone[]}`
- `PathSection = {id, label, eyebrow?, colour, steps}` — an orbit with its banner colour
- `PathStep = {id, label, note?, colour, state: 'done'|'undone'|'running'|'locked', glyph?, href?, intent?, value?, partial?, doneAt?, counted?, lockedReason?}`
- `PathMilestone = {id, at: 'half'|'end'|{afterStep}, label, reachedLabel?, reward?: {badge?, xp?}}`
- helpers: `pathSteps`, `pathProgress` (locked steps count toward the total; `counted: false` leaves a step out),
  `sectionProgress`, `nextStep` (the ZIGi anchor: first undone/running counted step), `stepIntent` (locked → none,
  value → stepper, href → open, else tick), `pathSegments`/`litSegments` (a line is lit when both dots are done; orbits are
  bridged), `milestoneState` (placement + reached), `zigiAnchor` (step + mood), `snakeOffset`, `stepAriaLabel`,
  `withStepState`, `normalisePath`, `pathProblems`.
- palette `PATH_COLOURS` (teal `--ring-emerald`, blue `--brand-blue`, magenta `--brand-magenta`, purple `--pillar-goals`,
  gold `--pillar-wealth`, pink `--pillar-health`, cyan `--pillar-habits`), `PAGE_PATH_COLOUR`, `PATH_NEON_STOPS` (the
  footer banner's main line).
