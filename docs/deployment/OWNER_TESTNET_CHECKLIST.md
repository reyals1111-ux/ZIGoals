# Owner testnet deployment and exit checklist

**Prepared, not deployed.** Use only `zig-test-2`; never mainnet or real funds. Stop on any mismatch. Funding and upload permission remain external prerequisites. No faucet request or transaction is automated by this checklist.

1. **Public developer address.** Select the dedicated Keplr test account; compare its full public `zig…` address in wallet/app/support approval. Never copy a seed or key.
2. **Test balance.** Read the official REST bank balance; denom must be `azig`, display precision18. Reserve estimated fees separately from the tiny smoke deposit. Zero balance means stop.
3. **Upload permission.** Obtain support confirmation for this exact address and verify current `wasm params` with the official CLI/query method. An unavailable query, HTTP501 or an unconfirmed allowlist means stop; do not probe by repeatedly uploading.
4. **Reviewed artifact.** Build and validate with pinned tools; use `artifacts/zigoals_goal_manager.wasm`, never raw target output. Save its actual size/hash, source commit and build environment from `artifacts/build-report.json`. The known Mac reference is 258540 bytes and SHA256 `090b19225a93fc191810426973001ab400452799d1925aadddadef1fc0cc6e25`; independent Linux results must be reviewed on their own evidence. A difference needs investigation, not a fabricated identity claim. Approve one exact artifact before upload.
5. **Upload.** Owner reviews/simulates and signs a testnet store-code transaction from that account. Record its locally computed/returned hash immediately. On timeout, check the existing hash; never blindly repeat.
6. **Code ID.** Wait for successful included receipt. Extract code ID from the correct store-code event; query code info and verify the onchain checksum equals the reviewed SHA256. Receipt success alone is insufficient.
7. **Immutable instantiate.** Owner signs instantiate for that code ID with `{"admin":null,"native_denom":"azig"}`, no funds, label `ZIGoals Goal Manager testnet`, and **no chain-level migration admin** (`--no-admin` in the official CLI). The JSON `admin` is optional deposit-pause authority, distinct from chain migration admin. Default both to none.
8. **Contract metadata.** Verify included instantiate receipt and contract address, code ID, empty chain admin, cw2 name `crates.io:zigoals-goal-manager`, version `0.1.0`, configured `azig`, null pause admin, deposits unpaused, zero initial recorded liabilities. Check live node chain/version/denom again.
9. **Configure frontend.** Validate the strict [v2 public manifest](MANIFEST_V2.md), place it in `apps/web/config/deployment.json`, rebuild and reopen. Legacy address/code-ID environment variables no longer enable financial actions. Guarded client must accept the actual reviewed contract; do not weaken identity checks if it refuses.
10. **Tiny Goal.** Create a Goal without funds. Verify correct owner and actual event-derived Goal ID. Name/target/date/private notes must not appear in the wallet execute message or chain event. Creation is not a deposit.
11. **Tiny deposit.** Example test amount: `1000000000000000azig` (0.001 test ZIG), if balance covers this plus simulated fees. Exactly one `azig` coin; record before/after bank balance, Goal position, liabilities and tx hash.
12. **Partial withdrawal.** Withdraw `400000000000000azig` (0.0004 test ZIG). Recipient is stored owner. Check Goal position is `600000000000000`; wallet delta includes network fee.
13. **Complete withdrawal.** Withdraw the exact remaining position. Check position and this Goal's liability contribution are zero; never send an extra deposit to recover funds.
14. **Close.** Close the empty Goal. Closed history remains queryable and further deposit/withdraw rejects. If pause admin was deliberately configured in a separate reviewed deployment, separately prove pausing deposits still permits exit.
15. **Events.** For each receipt verify code0, hash, height, matching sender/contract/execute message/funds, and events from this contract. Unknown or malformed receipt remains uncertain. Save public hashes; keep private plans offchain.
16. **Explorer verification.** Open the app's validated ZIGScan links. Range currently supports the official testnet homepage only; paste the public hash there manually if its search works. Do not invent a missing Range detail URL or call a link a proof.
17. **Balances.** Reconcile bank deltas including actual fees, Goal positions and contract liabilities. Contract balance must cover total liabilities. Any unexpected direct-transfer surplus must be explained; it is not withdrawable user credit.
18. **Manifest.** Save code ID/address, public deployer, artifact checksum, upload/instantiate/smoke hashes, heights, timestamps, source commit, chain/version/denom, instantiate JSON and both admin fields. Mark DEPLOYED only after all included receipts and read checks pass. Back up private Goal metadata separately.

Abort on mismatched chain/denom/address/checksum/code/admin, stale account, unexpected permission/message/funds/fee, inability to verify upload permission, receipt uncertainty or accounting mismatch. Do not retry ambiguous broadcasts. For a deployed defect, pause new deposits only if that authority exists, preserve user withdrawals, disable the frontend configuration and investigate. An immutable contract cannot be rolled back or patched in place; replacement requires a new reviewed deployment. Existing funds never move automatically to a replacement.

Use the complete [runbook](TESTNET.md) and [real Keplr checks](KEPLR_OWNER_CHECKLIST.md). The current v2 application manifest intentionally retains null live IDs/hashes and `PREPARED_NOT_DEPLOYED`; no transaction has been sent.
