# Alpha disclaimer

ZIGoals Alpha is experimental, unaudited software for local simulation and testnet compatibility testing. It is not investment advice, a savings account or a promise of returns. Simulated and testnet assets have no monetary value. Never use mainnet or real funds during this Alpha.

The public undeployed Alpha lets you create fictional plans and simulate deposits and withdrawals. Keplr connection is optional and does not place funds under management. Goal Manager is not deployed; financial blockchain actions are unavailable. A future deployed-testnet build requires separately reviewed source, configuration and owner authorization.

Keep private goal backups secure. Browser-local storage is not encrypted against device compromise, hostile extensions or malicious same-origin code. Check the actual environment and build identity before testing. Never enter a seed phrase or wallet key into ZIGoals. Report suspected security issues privately to **hello@zigoals.app**.
