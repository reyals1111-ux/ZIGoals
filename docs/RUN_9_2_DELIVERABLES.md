## Design decisions

- Keep one canonical accounting model. Showcase uses a scoped Storage adapter and session-selected profile, not seeded normal keys. Exiting remounts all private-store consumers. Market fixture evidence is separately identified and never persists to public caches.
- Add `/app/markets` as the single market-discovery destination; Wealth remains the owned portfolio.
- New modules: Portfolio Composition, Funding Agenda, Needs Attention, Habit Consistency, Nutrition/Meal Distribution. No trading or advice.
- Preserve normal v3 and archival evidence rules; fixture builder uses valid existing schemas.
