## Summary

What the chain allows today without a contract (all read live on 2026-10-18, 18:43–19:05 UTC): ZIGChain mainnet (zigchain-1, zigchaind v5.1.2, Cosmos SDK 0.53.8, azig with 18 decimals) exposes authz, feegrant, gov v1, staking, distribution, slashing, a native token factory (`/zigchain/factory/params`, 40 ZIG create fee), a native DEX (`/zigchain/dex/pool`), x/nft (present, zero classes, no public mint message), ICA, IBC-go v10 with an OPEN Cosmos Hub channel (cosmoshub channel-1555 ↔ zigchain channel-4). CosmWasm uploads are governance-whitelisted (`AnyOfAddresses`, 15 addresses on mainnet; instantiate `Everybody`); no name-service, DID or soulbound module exists. authz is genuinely used on mainnet (16 MsgGrant and 55 MsgExec transactions, mostly validators' own operations), but no REStake operator exists for ZIGChain (REStake's networks.json lists 70 networks without it; validators.cosmos.directory shows 0 of 19 validators with a restake entry). Every public LCD answers `access-control-allow-origin: *` on GET; the official api.zigchain.com sits behind Cloudflare and returns 403 on OPTIONS preflights and on `/cosmos/tx/v1beta1/txs?query=`, so browser reads with custom headers and transaction searches must use Polkachu/Numia/NodeStake or the app's relay. docs.zigchain.com, hub.zigchain.com and faucet.zigchain.com are behind a Cloudflare challenge (unreadable by automation); the docs were read from their GitHub source and several pages there are stale (uzig, 4 validators, Leap).

Ranked by user value × feasibility today: (1) Goal Vaults — a wealth goal backed by the person's real delegations, pending rewards, unbonding entries and stZIG balance, all read as exact integers; nothing moves; the goal↔position link stays on the device (ADR-003 allocations already exist). (2) Governance hub — proposals, tally and params are public reads; MsgVote (gov v1 for direct signing, v1beta1 for Keplr+Ledger amino) is fully supported by CosmJS 0.38.1; a vote costs ~91k gas (~0.00023 ZIG at the 2.5 gazig minimum); votes need bonded stake to count and are deleted from state at tally, so the app must keep its own vote journal. (3) Validator health — jailed/commission/missed-blocks reads with no personal data at all. (4) Rewards-to-goal sweep: because MsgDelegate auto-claims pending rewards (SDK hook, confirmed in the Hub docs), one MsgDelegate of the reward amount does the sweep without batching, which keeps EARN_DESIGN principle 3 intact. (5) Opt-in memo attestations (1 azig self-send, memo ≤256 chars, ~78k gas, read back by a sender-scoped tx search): cheap and contract-free, but public forever and only safe as a salted commitment or an opaque badge id, never a hash of a goal name. Waiting: authz auto-compound (no operator to grant to; CosmJS 0.38 has no amino converters for authz, so Ledger is excluded; "set and forget" contradicts EARN principle 3 — owner decision), feegrant (needs a funded ZIGoals key — owner decision, not built), pacts (escrow needs a contract), "Get ZIG" via IBC (the Hub channel brings ATOM, not ZIG; ZIG is on neither the Cosmos Hub nor the Osmosis asset lists; the swap needs the custom dex message types; hub.zigchain.com already does bridge+swap in one signature — deep-link and watch the balance), stZIG value (exchange-rate query still undocumented).

Repo constraints that gate the build: `packages/chain-config` validates zig-test-2 only and ADR-004 rejects mainnet signing unconditionally; `FINANCIAL_EXECUTION_ALLOWED` is true only for TESTNET_DEPLOYED; the public Alpha refuses mainnet position reads (`MAINNET_REFUSED`, Session Z-Cloud C4). So this session can ship Goal Vaults and the governance hub as read-only on both networks plus signed steps on testnet, and needs two explicit owner decisions for mainnet: lifting C4 for linked addresses through the relay, and a narrow exception for non-fund-moving messages (MsgVote). Note the live testnet unbonding time is 1,814,400 s (21 days), not the registry's 604,800 s, which lengthens any testnet undelegate receipt.
