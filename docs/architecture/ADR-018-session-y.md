deploy #34). This record holds every decision Session Y-Cloud took without asking the owner (the brief asks for the

## Assertions changed (deliberate, listed)

  migration commit (interrupted at pointer publication, and after the retry); B5 writes none for the Local Demo, so both

  `lib/vault/database-lifecycle.test.ts` (two tests) used the Local Demo space `'local'` or bare names (`'A'`, `'B'`);
  they now use account spaces (`account:…`), the only kind whose outbox sync reads. Every assertion is unchanged; the
  Local Demo's own behaviour has its own new tests.

  client's refused reads and writes, as before), and the Local Demo space is asserted empty before and after.
