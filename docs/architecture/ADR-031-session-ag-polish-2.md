## Decisions taken without asking

- **K4 — The phone's lanes, rebuilt (owner Part 1a, 1d, 1e; extended for the smooth line by owner amendment 5, K16).** `lib/path/phone-lanes.ts` now spreads the nodes across the whole width: each node travels from the one before it — or from its orbit's planet, for an orbit's first node — by a seeded rhythm (the path's id) of wide sweeps (about half the width) and short ones (about a third), toward the side with more room and now and then the other way, so neighbours never line up. Each tab hangs toward the free side and always shows the whole name on one line; a node moves along until it does; only a name too long even for the leftmost lane wraps (320 px), every line shown. ZIGi keeps its room beside a node where that costs the sweep little (within 7 % of the width); otherwise it takes its slot above the tab (AG Polish's `above`), so the path's width comes first.
