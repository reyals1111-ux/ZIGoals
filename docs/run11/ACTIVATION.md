## Capacity and cost assumptions
Planning example only:20friends ×20private edits/day =400edits/day. At roughly3encrypted mutation batches plus a cleanup per edit this starts around1,600DO requests/day, before reads, retries, admission, rotation and provider work. The measured2.5MB-domain test writes under100KB and downloads under30KB for one small field change; this is not a bound for arbitrary shifted JSON or first-device sync. Whole-domain initial transfer, imports and rotation are materially larger. Backpressure is visible and preserves local records.
Market fixture24concurrent requests/48pair-results used one provider batch and3synthetic credits; warm/restart shared cache avoided additional dispatch. A planning500distinct cold quote batches/month costs500×the confirmed endpoint credit cost, plus catalog/history/insights/token/RWA work and conservative dispatched failures. Shared caches reduce duplicate work, not all usage. Never extrapolate an unlimited allowance from a warm-cache test.
Current official pages checked2026-09-26: [Cloudflare DO pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/) lists Free100,000requests/day,13,000GB-s/day,100,000written rows/day and5GBSQLite storage; operations fail when a Free limit is exceeded. [Supabase pricing](https://supabase.com/pricing) lists Free50,000MAU,500MBdatabase and5GBegress, with inactive-project pausing. [Resend pricing](https://resend.com/pricing) has separate delivery limits. [CoinGecko pricing](https://www.coingecko.com/en/api/pricing) currently lists Demo100calls/min and10,000monthly calls; [credit guidance](https://support.coingecko.com/hc/en-us/articles/13962109374489-How-does-CoinGecko-API-count-the-API-usage-credit) counts all responses toward the minute limit. These are public references, not the owner's verified plan/usage. Reserve headroom; no paid upgrade is approved.

## Compatibility and recovery
Keep protocol1/epoch1 decoding and current indexed-store migration. New readers support positive rotation epochs, domain generations, selective chunks and reviewed conflicts; older app builds are not promised to read new optional fields or replay current journals. Preserve encrypted user backups and the current recovery secret separately from source. Rotating a secret requires retaining the next recovery secret before activation. Never restore old code over current stores to fix a UI defect; use current-code forward recovery and preserve the old queue.
Source archives restore source/config/templates only. They do not contain private browser data, cloud ciphertext, credentials, recovery secrets or the external deletion ledger. Hosted PITR is an owner acceptance exercise. A simultaneously stale vault, lifecycle authority and external checkpoint cannot establish latest deletion truth; keep serving paused if the independent latest checkpoint/account inventory is unavailable.
