## 3. Live data: server routes (one per source family)

Shared module `apps/web/lib/server/earn/upstream.ts` (`import 'server-only'`): `EARN_EGRESS = Object.freeze(['https://api.zigchain.com','https://testnet-api.zigchain.com','https://api.llama.fi','https://yields.llama.fi'])`; `fetchUpstream(url, {maxChars, timeoutMs=12000})` refuses any URL whose origin is not in the list (throws before fetching), `redirect:'manual'`, `credentials:'omit'`, `referrerPolicy:'no-referrer'`, non-2xx → `UPSTREAM_DOWN`, body > maxChars → `TOO_LARGE`, JSON then `zod .strict()` schema → `MALFORMED`, then range predicates from `apps/web/lib/earn/live/ranges.mjs` → `OUT_OF_RANGE`. `earnCache(name, ttlMs, staleMs=600_000)`: in-memory per isolate, one in-flight promise shared, last good answer served with `stale:true` for up to 10 min after a failure, never a failed answer. Rate limits reuse the positions-relay shape (`marketClientGroup(cf-connecting-ip)`, 30 reads/min/client, 300/min/server, 429 + `Retry-After`). Every route: `export const dynamic='force-dynamic'`, headers `Cache-Control: no-store`, `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`, GET only, any query key outside the allowed one → 400.

Answer envelope (200 for both outcomes — unavailability is a normal state the page renders; the hosted verifier counts ≥400 as a failure):

```json
{"version":1,"status":"ok","source":{"name":"ZIGChain mainnet LCD","url":"https://api.zigchain.com"},"height":"13043201","observedAt":"2026-10-18T19:25:13Z","fetchedAt":"…","stale":false,"data":{…}}
{"version":1,"status":"unavailable","reason":"UPSTREAM_DOWN","message":"ZIGChain's public API did not answer just now.","source":{…},"checkedAt":"…"}
```
Reasons: `UPSTREAM_DOWN | TIMEOUT | TOO_LARGE | MALFORMED | OUT_OF_RANGE | WRONG_NETWORK | PIN_MISMATCH | RATE_LIMITED`.

"updated x min ago" is computed from `fetchedAt` with a 30 s ticker; past 15 min the figure wears a "stale" ring and the words "last read 17 min ago".

**APR shown on the native card**: `about 5.74 % a year gross` → `after the network's 2 % tax: 5.63 %` → `with a 5 % validator commission: 5.35 %` (10 %: 5.06 %). Tap "How this is computed" → `APR = annual provisions ÷ bonded ZIG; × (1 − community tax) × (1 − commission). Simple rate; rewards are not compounded unless you re-stake them. Read from the chain at block 13043201.` Never "APY" for native staking; DefiLlama's `apy` is shown as "DefiLlama's figure (third party)".

## Risks

- Older-reader breakage if anyone adds 'earn' to PAGE_IDS/BUTTON_IDS or DASHBOARD_BUILTINS: Zod 4 strict enums make the whole synced settings record unreadable on #37–#43 (verified with node). Mitigation: device-only keys; frozen-readers run at Gate C; a unit test asserts PAGE_IDS/BUTTON_IDS/DASHBOARD_BUILTINS are unchanged.
- Live sources can disappear or change shape (api.zigchain.com behind Cloudflare; Valdora can migrate the contract; DefiLlama slugs). Mitigation: pins, strict schemas, ranges, 'unavailable' with reason, stale-while-error, the live-check script left for the owner.
- Hub, faucet and docs.zigchain.com are bot-walled: Phase B cannot capture them by automation; the owner's browser must provide those captures or the Hub steps stay text-only with a note.
- C4 keeps mainnet address reads off the public Alpha: the hero's live summary and steps 4–5 cannot be detected there; honest copy and manual ticks until the owner decides.
- Weight: the hub is a long page; if the measured /app/earn exceeds what the owner accepts, more sections must lazy-load (validators, illustrations already do); the shell line must not grow past 447 kB — the dock shell is capped at ~3 kB gzip or loads after hydration.
- Verifier renumbering (earn at 7) shifts landing/recipe; any owner script or doc citing stage numbers needs the new numbers (STATUS records them).
- Third-party figures (DefiLlama APY/TVL) could be read as ZIGoals' claims; every such figure is labelled third-party and never ranked or summed with chain figures.
- Legal: promoting staking/stZIG/LP to EU consumers and showing APR may fall under MiCA Art. 66 / FSMA rules (LEGAL_CHECKLIST §6); copy keeps 'no promises', sources and dates, and the owner's lawyer gate remains before mainnet signing.
- Illustrations redrawn from captures must not reproduce third-party logos/text beyond layout; a review line in docs/earn/ILLUSTRATIONS.md per asset.
- Polling while visible across five families: with many tabs a Worker isolate could see bursts; per-client 30/min limit and 60–120 s TTLs keep upstream calls bounded (worst case ≈ 1 upstream batch per family per TTL per isolate).
