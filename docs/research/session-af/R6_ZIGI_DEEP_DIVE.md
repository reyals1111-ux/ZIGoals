## Summary

ZIGi on origin/main (4f92495, read 2026-10-18 20:36+02:00) is far more complete than the owner's seeds assume. Three of the six seeds already exist in some form and should be reframed as extensions, not new features.

What exists today. ZIGi runs on four brains: (1) no AI — a deterministic English lookup engine over ~40 read-only tools (habits, goals, Health behind a three-part gate, sleep, meditation, wealth incl. a watch-only `staking_watch`, accounts, chess, links, `about_me`), plus Chrome's on-device Prompt API (Chrome 148+, English-only options) for rewording; (2) the person's own key, browser-direct, to OpenAI, Anthropic, Gemini, xAI, OpenRouter (PKCE) or a localhost Ollama/OpenAI-compatible server; (3) a clipboard bridge to subscription apps; (4) "ZIGoals hosted", a Cloudflare relay (Claude Sonnet 5.5 / Haiku 5.5 or OpenAI), invite-only, budgeted, and off in every shipped build. Every write is a whitelisted proposal card (85 `ACTION_KINDS` + 3 composites, max 10 per reply) validated by Zod, applied through the same store mutators as the forms, undoable, logged in "Actions by ZIGi", with per-kind auto-accept and a daily cap; money is pre-fill only (4 `PREFILL_KINDS`). Device-only records a card may patch are enumerated in `DEVICE_WRITE_KEYS` (habit-extras, micro-targets, macro-mode, health-coach, game, goal-extras, average-goals, calculator, life-review). Memory ("What ZIGi knows about me") already is device-only, opt-in, ≤100 notes × 500 chars, editable, forgettable per note, in Export, never synced, secret-shape refusing, Health notes gated — exactly seed 2. Voice: browser speech recognition (Chrome on-device where offered) or OpenAI transcription with the person's key, four languages (en-GB, en-US, nl-BE, nl-NL), ≤60 s, single shared engine, tap/hold, read-aloud via speechSynthesis with a matched device voice, a spoken-form normaliser (EN/NL numbers, clock idioms, fillers, self-corrections). Proactive: a 3-line morning brief, suggestion chips, weekly review, pattern insights, knock on due reminders (quiet hours, ≤3/day), and a separate evening wrap-up card (mood + intention). Tests: a deterministic golden set (~352 entries, 100 % in CI, mock replies only), a spoken golden set, a model-scored corpus (typed + 719 held-out spoken cases) with a pure scorer, a real-model harness (`ZIGI_REAL_MODEL=1`, local Ollama or Anthropic with `ANTHROPIC_TEST_KEY`) and a monthly batch eval (~$2.50/month).

Comparison. Against ChatGPT (memory with view/delete, scheduled tasks 3–15 per plan, agent mode retired in favour of "ChatGPT Work" and always-on "dots"), Gemini Live (continuous interruptible voice, camera, screen share, memory in US English only), Copilot (memory dashboard, Actions; Mico being removed from voice; Copilot Health paused), Character.ai (Story Memory/Facts, calls), Replika 2.0 (3D avatar, voice, video), Grok companions (5 personas, NSFW mode, push nudges), Finch (pet, streaks, free core), Duolingo Lily (facts list memory across calls), Home Assistant (local-first command handling, LLM fallback, MCP), and the dead or pivoted ones (Dot wound down, Humane off since 2025-02-28, Pi stagnant, Open Interpreter now a Codex fork), ZIGi lacks: continuous hands-free conversation, scheduled/clock-driven briefs delivered as notifications, Dutch on-device answers, screen/camera awareness, automatic memory, multi-step plans as one bundle, and any Earn education with live rates.

Ranked proposals (all testable with golden/mocked cases, no paid calls): 1 Daily Brief v2 + Evening Recap (extend `morningBrief`/wrap-up, read aloud, new brief sections, device-only); 2 Plan bundles ("set me up for a 10k") as a new composite expanded to existing kinds with per-item accept via `applyAll`; 3 Checklist-by-voice hardening (spoken check-ins/timers already route to `check-in`, `start-timer`, `start-night`; add a Today "quick list" + NL spoken cases); 4 Earn coach (education + `staking_watch` + a new verified read-only rates tool; staking pre-fill needs an owner policy decision since ZIGI_ACTIONS_Z says "no"); 5 Dutch on-device answers and brief (a real gap vs every competitor); 6 Page awareness "Explain this" (extend "Ask ZIGi about this"); 7 Memory v2 (only the delta: model-proposed `remember` cards from plans/briefs, memory shown in briefs). Real-model round: measure pass rate per kind, field fidelity, facts, refusals, latency, tokens, cost per case; measured baselines are Sonnet 5.5 $0.0080–$0.0129/turn (94.8–97.5 %), Haiku 5.5 $0.0005–$0.0006/turn (92.1–94.9 %), Opus 5.5 ~$0.02/turn (95.8 %), prices as of 2026-10-10.

## 3. Gap list (ZIGi vs the field, ordered by how much a 4-in-1 life + wealth app would feel it)
1. **No continuous, interruptible voice conversation** (Gemini Live, ChatGPT Voice): ZIGi listens once (≤60 s, `continuous=false`), reads one reply aloud; no barge-in, no hands-free loop.
2. **No clock-driven briefs or scheduled tasks delivered as notifications** (ChatGPT scheduled tasks, dots): the brief is computed on view; the knock needs the app open; push payload is `{"v":1}` with names only.
3. **Dutch is model-only**: on-device answers, the brief, chips, review and insight wording are English; whole-Dutch questions go to the model (golden `nl-question` → none). The owner's voice defaults (nl-BE) make this the sharpest gap for a Belgian user.
4. **No screen/camera awareness** (Gemini Live, Copilot Vision): page records are attached and "Ask ZIGi about this" exists on number cards, but there is no "explain what I am looking at" for every card, and no image of the screen (by design: privacy).
5. **No automatic memory** (ChatGPT, Copilot, Character.ai Facts, Duolingo's facts list): ZIGi keeps nothing unless the person confirms a `remember` card — a deliberate privacy choice; the delta is that the model rarely proposes `remember` cards and memory is not visible in briefs.
6. **No multi-step plan as one object** (dots/Work deliverables): `plan-goal`/`build-habit` composites and up to 10 cards exist, but a "set me up for a 10k" bundle (goal + habits + reminders + time-of-day + challenge) has no single reviewable container, no template library beyond `goal-from-template`, no staged weeks.
7. **No Earn education with live data**: `staking_watch` is watch-only; no APR/unbonding/rewards tool; "never invent rates" + "no financial advice" rules leave the Earn pillar with nothing to explain the person's options.
8. **No companion nudging loop** (Finch, Grok push, Duolingo): by design ZIGi never nags (one card, one dismissal); knock ≤3/day. Not a gap to close, a principle to keep.
9. **No image/video avatar calls** (Replika, Duolingo, Grok): the mascot is a 25-state animated figure; no lip-sync. Low value for this app.
10. **No local-first command handling for every intent** (Home Assistant's "Assist first, LLM fallback"): ZIGi does this for lookups and navigation, not for logging/planning (those always need a model, or Quick add's narrow grammar).
