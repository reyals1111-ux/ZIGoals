# QA sweep 2026-09-30 (Session F): user simulation, logic fixes, regression tests

Branch `qa/user-sweep-2026-09-30`, [PR #51](https://github.com/reyals1111-ux/ZIGoals/pull/51). Base: `main` `d21ba8f` (includes #50). Nothing was merged or deployed.

## Summary
- **Scope:** four personas were driven through a production build of `main`, on desktop and tablet, with simulated days, weeks and months. A torture matrix followed:
  - time: both 2026 DST ends, rollovers, year end, leap day 2028;
  - locales: nl-BE, fr-BE, de-DE, en-US;
  - backups, storage and inputs;
  - honesty, privacy and network, accessibility, performance.
- **Findings:** 38 in total, 7 fixed and 31 open.

  | Severity | Total | Fixed | Open |
  |---|---|---|---|
  | Blocker | 1 | 0 | 1 |
  | Major | 8 | 3 | 5 |
  | Minor | 19 | 4 | 15 |
  | Polish | 10 | 0 | 10 |

- **The one blocker (UI lane):** Health number fields silently drop a typed decimal comma in Chrome with an English UI. "72,5" kg is saved as **725 kg** with "Weight saved." The lib half, the parser, is fixed here; the field type needs a UI change.
- **What held up well:**
  - Journal dates, streaks and weeks were correct every day for 7 simulated weeks across 25 Oct, and at every calendar edge tested.
  - Backups round-trip exactly. Bad files are refused with the stored bytes unchanged, and tampered encrypted files are refused.
  - No personal value appears in any request, and no request goes to a third-party host.
  - Currencies are never summed or converted, and unknown kcal shows as "Unknown".
  - There are no unnamed controls, focus rings are visible, and nothing animates under reduced motion or Motion Off.
- **Security:** nothing exploitable was found. The one CSP event (QA-25) is a blocked, harmless eval probe.

## Method and evidence
- **Build:** `NEXT_PUBLIC_APP_ENVIRONMENT=PUBLIC_ALPHA_UNDEPLOYED pnpm build`, then `next start` on 127.0.0.1.
- **Tooling:** Node 24.19.0, pnpm 11.19.0, Playwright 1.63 using the `chrome` channel. Locally that channel points at the sandbox's Chromium 141, whose UI language is English.
- **One browser at a time.** The drivers are scratch Playwright scripts and are not committed; everything worth keeping became a deterministic unit test.
- **Viewports:** 1440×900, 1280×800, 1024×768 and 820×1180 (touch). At 820 px the app uses the phone-style top navigation, which is Session E's area, so no layout findings are filed from it.
- **No provider:** every `/api/market-*`, `/api/food-lookup` and `/api/positions` request was answered with a 503 fixture, and any request to another host was recorded and aborted. So "no price service" is the tested state, not a failure.
- **Evidence labels:**
  - **browser**: reproduced in the production build;
  - **unit**: a failing-first or regression test in this PR;
  - **code**: found by reading the code, not reproduced.
- **Screenshots:** Showcase or fictional data only, on the review branch (never merged). The link is in one PR comment.

## Logic backlog and design notes (not fixed here)
- **QA-04, plan and funding days in UTC.**
  - The UTC choice is deliberate and visible ("Dates use UTC").
  - A change would move installment boundaries for existing plans and is visible across synced devices, so it needs an owner decision and its own TIER 3 PR.
  - Option: compute `today` in `fundingHealth` (`lib/goal-intelligence.ts:59`) and in plan revisions (`lib/plan-revisions.ts:5`) from a stored plan zone, defaulting to UTC for existing plans.
- **QA-02, recovery-copy retention.**
  - Removing old `:recovery:` copies deletes user bytes, so it needs owner approval.
  - Proposed: keep only the newest copy per key; prune older copies only after a successful restore, and after the user has downloaded an export in the same session.
- **QA-14, `parseUnits` and a decimal comma.** `packages/chain-config/src/index.ts:57-68` also parses chain amounts, so it was not touched (wallet lane). A form-level normaliser (trim, then the same unambiguous-comma rule as Health) would keep chain parsing strict.
- **QA-35, duplicate `assetEvents` IDs.** Rejecting them makes stored data that has duplicates unreadable, which is a format tightening. Safer: de-duplicate on write and report on read.
- **QA-25, zod eval probe.** `z.config({jitless:true})`, run before the first schema parse on the client, avoids the probe. It must be imported first in the client bundle.

## Checks that passed
All were observed in the browser unless noted.
- **Time:**
  - the journal date is right on each of 49 days across 25 Oct, and on the repeated 02:30 hour;
  - New York 1 Nov 01:30 (second pass), year end in New York and Brussels, and 2028-02-29 all show the right journal days;
  - Robin's streaks are 33 days after the missed 20 Oct;
  - the Monday–Sunday week spans the DST change;
  - unit (`calendar-zones.test.ts`): 42 cases under UTC, Brussels and New York; 54/54 including the weight tests under host TZ UTC, Brussels, New York, Auckland and Kolkata.
- **Backups:**
  - plaintext and encrypted round-trips are exactly equal for Goals, Habits and Health;
  - refused with bytes unchanged: truncated, invalid JSON, wrong module, future version, duplicate IDs, empty file;
  - accepted: a BOM prefix, and v1 Habits (migrates);
  - encrypted: a wrong secret and a tampered file are refused;
  - a 4.4 MB module is refused ("under 2 MB");
  - unit (`export-roundtrip-records.test.ts`): counters, measurements, timers, financial evidence and v1 Habits.
- **Privacy and network:**
  - all 10 pages in the empty, data and Showcase states, plus a goal detail page;
  - 0 requests with a sentinel value in the URL, query or body;
  - 0 third-party hosts;
  - the Health-only preset sends no market or positions request (and hides the Alpha bars, by design);
  - no console errors beyond the 503 fixtures.
- **Honesty:**
  - the honesty banners are on every page in every state (except the Health-only preset, by design);
  - currencies are never summed;
  - no prices are invented with the provider down.
- **Accessibility:**
  - 0 unnamed controls on 10 pages (Showcase data);
  - one `h1` per page;
  - focus rings on all 30 tab stops tested on Today;
  - native modal dialogs;
  - no running animations under reduced motion or Motion Off;
  - text contrast AA everywhere measured, except disabled buttons, which WCAG exempts. Text on gradient buttons could not be measured this way.

  - two tabs stay consistent (simultaneous completes give one entry);
