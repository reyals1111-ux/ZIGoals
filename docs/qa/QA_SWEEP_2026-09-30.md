# QA sweep 2026-09-30 (Session F): user simulation, logic fixes, regression tests

Status: **in progress**. This file is filled in as the parts land. Branch `qa/user-sweep-2026-09-30`, base `main` `d21ba8f` (includes #50).

## Method
- **Build under test:** a production build of `main` (`NEXT_PUBLIC_APP_ENVIRONMENT=PUBLIC_ALPHA_UNDEPLOYED`), served by `next start` on 127.0.0.1.
- **Environment:** Node 24.19.0 and pnpm 11.19.0. Playwright 1.63 with the `chrome` channel pointed at the sandbox Chromium 141, local only.
- **Viewports:** desktop and tablet only, at 1440×900, 1280×800, 1024×768 and 820×1180 (touch). Phones are being redesigned by Session E on `ui/mobile-experience-2026-09-30`, so they are out of scope here.
- **No provider:** every `/api/market-*` and `/api/food-lookup` request gets a 503 fixture. Any request to another host is recorded and aborted.
- **One browser or test run at a time,** at most 2 Playwright workers.
- **Personas,** driven with Playwright clock control, `locale` and `timezoneId`:

  | Persona | Locale / time zone | Viewports | Focus |
  |---|---|---|---|
  | Nina (new, non-crypto) | en-GB / Europe/Amsterdam | 1440×900, 820×1180 | First visit, empty states, first goal/habit/health entries, Settings, backups, Showcase, Motion Off |
  | Tom (wealth) | en-US / America/New_York | 1280×800, 1024×768 | EUR and USD positions, manual valuations, no price service, allocations, goal funding over months |
  | Robin (Belgian daily user) | nl-BE / Europe/Brussels | 1024×768, 1440×900 | Daily food, water, counters and habits for 7 weeks across the 2026-10-25 DST change |
  | Power user | en-US / Europe/Brussels | 1440×900, 820×1180 | Years of history, 45 habits, large backups, two tabs, reload mid-save, offline and back |

- **Torture matrix:**
  - time: DST ends 2026-10-25 and 2026-11-01, midnight rollovers, a journal time zone change, month end, year end, leap day 2028-02-29;
  - locales: nl-BE, fr-BE, de-DE, en-US;
  - backups: round-trips, bad files, Showcase, large;
  - storage: quota, cleared data, private mode, two tabs, slow read;
  - inputs;
  - honesty, privacy and network, accessibility, performance.
- **Fix lane:** logic bugs in `apps/web/lib/**`, `packages/**` and `workers/**`, outside Session E's files. Each fix has a failing-first test and its own commit. UI, layout and copy issues go to the backlog below.
