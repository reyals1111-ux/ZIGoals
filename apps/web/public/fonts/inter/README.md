# Inter (self-hosted)

Used only when a person chooses **Font: Inter** in Settings → Appearance → Customize (Session AJ, item 32, D5). The
`@font-face` rules live in `apps/web/app/customize.css`; only `html[data-font="inter"]` names the family, so the files are
fetched only then.

- Font: Inter 4.1 by The Inter Project Authors (https://github.com/rsms/inter)
- Source: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip (official release v4.1)
- Downloaded: 2026-10-30. Only the files below were taken from the archive; nothing in it was run.
