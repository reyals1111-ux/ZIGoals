- Preserved V1 identifiers, descriptions, notes, Goal links, rule dates/states/schedules/targets, entry dates/counts/notes, and timestamps.
- Added dated prospective rules for BUILD/QUIT/LIMIT, measurement, target period, recurrence, end conditions, pause, and archive.
- Added daily, weekdays, every-N-days, times-per-week/month/year, month-date recurrence, and daily/weekly/monthly/yearly targets.
- Added complete/partial/due/skipped/failed/paused/archived/not-scheduled/future statuses with distinct type semantics.
- Added smart completion, safe +/- controls, set/add value, manual history edits, duration timer, reflections, mood tags, and private notes.
- Added day/week/month/year trends, calendar, streak board, success/fail/skip distribution, consistency, and mixed historical-rule statistics.
- Added time-of-day/custom-area/Goal-link filters, templates, stack metadata/UI, completion/date/Goal end-condition architecture.
- Integrated private Goals as `private`/`local`/numeric links routed to `/app/goals/tracked/<id>` while retaining contract Goal links.
- Timer works only while the page is open; browser-closed reminders are intentionally absent.
- Stack relationships are descriptive only; no automation is claimed. Linked-Goal end conditions do not auto-stop until Goal progress is integrated.
- Historical rules are visible but have no history-editing UI; existing dated rules remain immutable through normal edits.
