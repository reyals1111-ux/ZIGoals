## B. NOVA holographic HUD (owner addition, 4 Nov)

**The owner's words:** a visual upgrade of the NOVA dashboard: widgets, cards, health bars, progress bars should look like holograms on top of the dashboard / liquid-glass panels with neon-coloured data relevant to the person's tracked cards and widgets (for example health widgets show hearts, progress bars, kcal and more in neon pink). Widgets on NOVA should look visually different from the rest of the app, feeling like a true futuristic heads-up display. It should truly stun people visually and make them feel in control of their whole app, like a hero in a command suit. It must work flawlessly with the app and interconnect the way the Checklist does. A lot of reasoning and time may go into it.

**The owner's reference image** (a stock concept image; described here instead of committed, because it is a watermarked stock picture): one large, slightly tilted glass panel floating in space (a gentle static 3D perspective, the right edge further away), a deep indigo-to-violet glass body with a soft magenta outer glow and a thin bright rim. On it: stacked horizontal neon bar meters (violet, pink, cyan, amber) in the top-left; a thin glowing line chart in a framed box; a large bar histogram in pink/violet with cyan tips and a glowing line running through it; a wireframe region map; a big flowing amber/orange wave line with a pink glow along the bottom third, over fine horizontal grid lines and a row of thin vertical tick bars; several circular dials: concentric segmented rings, radial gauges with a bright arc and a centre number, a lens-like ring with a cyan/magenta gradient; tick-mark rulers and dot sliders down the left edge; little HUD corner marks; everything with bloom/glow on the strokes, crisp thin lines, dark glass behind them and light floating particles.

**What to build (the session designs the details and records them in ADR-037):**
- **A HUD visual system for NOVA's widgets** ("Holo"), the default look on NOVA; the existing card look stays selectable ("Classic") in NOVA's Make it yours. The rest of the app keeps its cards.
- **Holo panels:** liquid-glass panels floating above NOVA's star system in depth layers (a far grid plane, mid panels, near glow), a neon rim in the widget's pillar colour, HUD corner brackets, a faint grid or scanline texture, glass refraction (backdrop-filter), an occasional shimmer sweep (O5), and a gentle static perspective on large panels. Never pointer-driven.
- **Neon data per pillar** (the pillar hues, made luminous): **Health = neon pink/magenta** (kcal ring with tick marks, segmented health bars for kcal, protein/carbs/fat, water, sleep and steps against their targets, hearts that fill by the share of a target, a heart-rate line only when real heart data exists); **Habits = cyan** (orbit streak rings, 7-day segmented bars, a consistency dial); **Goals = violet** (progress arcs with milestone ticks, a pace line with a labelled projection band); **Wealth = gold/amber** (a glowing net-worth line, a segmented allocation dial, a mini purpose flow); the Checklist (today's orbit ring), Tasks (due/overdue counters, today's queue), Agenda (a 24-hour radial clock with the day's items), Notes (recent captures), and a central core around the NOVA orb: four concentric pillar rings that summarise today.
- **Truth:** every figure comes from the same stores and functions the pages use (one source of truth; the same rounding); unknown shows "—" with the reason; no decorative element may look like data (ornaments are clearly ornaments: rings, ticks, brackets). Projections are labelled.
- **Interconnected like the Checklist:** tapping a widget opens quick actions that write real records with the normal Undo (log 250 mL water, tick a habit, log weight, start a focus timer, add a task, add to a goal); every change anywhere in the app updates the HUD live, and HUD actions update every page live (store subscriptions; other tabs through the existing cross-tab mechanism); the widget → page morph AK left unbuilt (View Transitions; Motion Off = plain navigation).
- **Arrange:** add, remove, resize and reorder widgets (keyboard accessible), presets ("Command", "Health HUD", "Wealth HUD", "Minimal"), saved device-only (TIER 3 stored format, frozen readers, export/restore/erase/catalog).
- **Themes:** Nebula and Dark in full neon; Light keeps NOVA's HUD as a dark island (Light's dark-islands rule). Theme parity tests updated deliberately, never weakened.
- **Accessibility:** every widget has a text/table equivalent and a clear name; numbers ≥ 4.5:1 (glow is decoration, not the contrast carrier); no meaning by colour alone; focus visible; WCAG 2.2 AA.
- **Phones:** NOVA stays simplified on phones (owner rule): the same Holo widgets in one column, lighter effects.
- **Performance:** SVG + CSS (transform/opacity) + at most one Canvas 2D layer for particles; no WebGL library and no dependency; 60 fps at CPU 4× on a mid laptop profile; idle CPU near zero when still or hidden; HUD code loads on NOVA only (its own route line, measured + 10 %; existing budgets never raised).
- **Copy:** never "Jarvis", Iron Man, Marvel or any other brand in UI copy or assets; no copied artwork.
- **The bar:** a fresh design-critic agent (it built none of it) judges it at 1440 and 1920 px in all themes and motion modes against this description and the best sci-fi HUD design practice, and the session fixes every finding; a fresh "first-time viewer" agent writes whether it stuns; both reports in docs/review/session-al/.
