# Denver — competitor features per page (brief lists for the Nov 4 run)

Purpose: the "what's missing vs the top competitors" line each page section in denver.md needs. Compiled 2026-11-04 from the Oct 26 feature-gap files; nothing new was fetched. Re-check every ZIGoals HAS/MISSING on the new build before you write it up.
Source labels (from the cited files): **PRIMARY** = vendor page/help/store listing/vote board read on 26 Oct. **SECONDARY** = third-party or rival-vendor page, Reddit/search summary. **UNVERIFIED** = no source opened in the team files; this is general product knowledge, so check it before you quote it.
File keys: GC = denver-parts/research-goals-competitors.md (§ = section), TK = tokyo-gaps.md (matrix row #), MO = moscow-gaps.md, LC = lisbon-checklist.md, BG = berlin-gaps.md, NH = nairobi-parts/habits-missing-ranked.md, DZ = denver-zigi.md.

## 1. Goals (top 5 by ratings proxy: Notion, Todoist, Finch, Strides, Qapital; plus Griply, Monarch, GoalMap, Lifetick)
1. Pace line / "on track by date" chart that raises the daily amount after a missed week: Strides, Griply. PRIMARY (GC §3.2, §8.2)
2. Four tracker types (Habit, Target, Average, Project) plus 150+ templates and a 3-step SMART wizard: Strides. PRIMARY (GC §3.2)
3. Hierarchy (Life Areas, Vision, Goals, Subgoals, Projects, Tasks/Habits), with one habit able to "contribute to" several goals: Griply. PRIMARY (GC §8.2)
4. Automated funding rules (Round-up, Payday, 52-week, Guilty Pleasure, Apple Health rule): Qapital. PRIMARY (GC §7.2)
5. Shared goals and accountability partners: Strides 18.0, Qapital Dream Team, Monarch household. PRIMARY (GC §3.2, §57.3, §13.2)
6. Pay-down (debt) goals with payoff date and interest saved: Monarch Goals 3.0, YNAB targets. PRIMARY (GC §13.2, §14.2)
7. Goal progress widgets (lock screen and home screen) and Watch: Griply, Todoist, Finch; Strides only has "launch" complications. PRIMARY/SECONDARY (GC §52)
8. Honest completion that keeps the real % ("complete at 72%, still reads 72%"): Griply 3.52.1. PRIMARY (GC §8.2)
9. Reminders: unlimited per goal, every-X-days, location reminders (requested): Strides. PRIMARY (GC §3.2, §3.4)
10. Most-voted requests ZIGoals could answer: time logged in h/min (1,046 votes), a custom congrats message (825), import from Excel or another app (48), a life-score radar (36), "why/obstacle" prompts when setting a goal (35). Strides UserVoice, PRIMARY (GC §3.4, §54)
